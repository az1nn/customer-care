# Referências

Este arquivo lista as referências e documentações oficiais utilizadas para a construção das informações apresentadas no README do projeto template-frontend.

## Ferramentas e Tecnologias

- Husky

  Documentação oficial para configuração e uso dos hooks do Git:

  https://typicode.github.io/husky/

- Storybook

  Plataforma para desenvolvimento e documentação de componentes isolados:

  https://storybook.js.org/

- Conventional Commits

  Padrão para mensagens de commit que auxilia na manutenção do histórico do projeto:

  https://www.conventionalcommits.org/

- ESLint

  Ferramenta de linting para garantir a qualidade e a consistência do código:

  https://eslint.org/

- Prettier

  Formatador de código que assegura consistência no estilo:

  https://prettier.io/

- Jest
  Framework para a execução de testes unitários e garantia da confiabilidade do código:

  https://jestjs.io/

- Vite

  Bundler e servidor de desenvolvimento rápido para aplicações web modernas:

  https://vitejs.dev/

- PNPM

  Gerenciador de pacotes utilizado para instalação e gerenciamento das dependências:

  https://pnpm.io/installation

- @originjs/vite-plugin-federation

  Plugin que possibilita a implementação do Module Federation com Vite:

  https://github.com/originjs/vite-plugin-federation

## Considerações Finais

Essas referências foram consultadas para assegurar a precisão e a relevância das informações apresentadas no README do template-frontend. Recomenda-se a consulta direta às documentações oficiais para obter mais detalhes ou atualizações.
